# Landing Page — Marcelo Borges

Landing page estática e responsiva inspirada no projeto criado no Base44.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador.

Para trabalhar no VS Code com atualização automática, instale a extensão **Live Server** e clique em **Open with Live Server**.

## Arquivos

- `index.html`: conteúdo e estrutura da página
- `styles.css`: todo o visual e responsividade
- `script.js`: menu mobile, animações e links do WhatsApp
- `assets/favicon.svg`: ícone da aba do navegador

## WhatsApp

`55 11 99500-4187`

```js
const WHATSAPP_NUMBER = "5511995004187";
const WHATSAPP_MESSAGE = "...";
```
